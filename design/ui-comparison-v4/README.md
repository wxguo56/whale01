“暂选”只保存在当前浏览器，不改变工程实施状态。角色、几何图形、唱片和卡带均为代码绘制的矢量参考；未调用生图服务，未修改原生App界面。

更新源码后运行 `node design/ui-comparison-v4/build-preview.mjs` 生成离线HTML。原生实施须按选定方案提取组件与参数，绑定真实任务和音频状态，另行完成真机验收。
