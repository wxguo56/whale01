# 代号鲸鱼01：设计规范系统（Design System v1.0）

## 1. 设计原则

1. **对话即主页**。无常驻底部导航；任务、设置为顶部轻量入口。
2. **一个入口做一件事**。文字、附件、语音统一从底部输入区进入；语音是唯一明确的切换按钮，有文字时变为"发送"。空文本提交不进入语音。
3. **角色小而有生命**。鲸鱼角色面积小，仅语音/任务状态时成为视觉中心；不常驻大角色卡。
4. **真实优先**。进度、结果、成功判定全部来自真实状态；不用计时器、随机波形冒充。
5. **克制的折光感**。深石墨底 + 薄荷青强调；光只强调活动状态和当前操作，不做大面积发光与装饰堆叠。
6. **状态不只靠颜色**。图标 + 文字 + 色调三重表达，服务动态字体、VoiceOver 与 Reduce Motion。

## 2. 色彩体系

深色为默认主题，浅色为完整对等主题。语义名以 tokens.json 为准。

| 语义 Token | 深色（默认） | 浅色 | 用途 |
|---|---|---|---|
| bg-page | #111C22 | #E9EFF0 | 页面背景 |
| bg-surface | #1C2C34 | #F7FAF9 | 卡片、面板 |
| bg-surface-raised | #223540 | #FFFFFF | 浮起内容（迷你播放器） |
| bg-input | #16242C | #EFF4F4 | 输入框 |
| bg-overlay | rgba(10,16,20,.55) | rgba(32,53,60,.45) | 遮罩 |
| text-primary | #EEF5F6 | #20353C | 正文 |
| text-secondary | #AFBEC7 | #526971 | 次级说明 |
| text-tertiary | #7E939E | #7C9199 | 辅助提示（不承载关键信息） |
| text-on-accent | #0E2A26 | #FFFFFF | 强调色上的文字 |
| accent | #A6EBDD | #246453 | 主按钮、链接、活动状态 |
| accent-pressed | #8AD9C9 | #1B5041 | 按压态 |
| accent-muted | 16% 透明薄荷 | 12% 透明深青 | 选中底、轻强调背景 |
| separator | #2A3D47 | #D3DEE0 | 分隔线 |

状态色（深/浅）：success #8FD9B0 / #2E7D53；warning #EFC97F / #9A6B12；error #F09A8E / #B3402F；info #9CC8F0 / #2C639B；pending（待核对）#C9B7E8 / #6B4FA0。

对比度已核：正文 ≥ 12:1，次级 ≥ 5.5:1，accent 及其上文字 ≥ 7:1，全部满足 WCAG AA。

**规则**：不引入第三种品牌色；状态色只用于状态语义，不用于装饰；accent-muted 用于选中与活动底色，避免大面积实色薄荷。

## 3. 字体体系

系统字体（SF Pro / 苹方），跟随动态字体。全部文字支持放大换行。

| 级别 | 字号/字重 | 用途 |
|---|---|---|
| largeTitle | 28 / 600 | 主页问候 |
| title | 25 / 600 | 页面与 sheet 标题 |
| cardTitle | 17 / 600 | 卡片标题、主按钮文字 |
| body | 17 / 400 | 对话正文（基准字号） |
| secondary | 14 / 400 | 来源、时间、次级说明 |
| caption | 12 / 500 | 徽章标签（不承载关键信息） |
| mono | 12 / 500 | 等宽辅助标签（编号、口径） |

正文行高 1.45，标题 1.2。**必要时间和金额用 body 或 cardTitle，不得压成小字。**

## 4. 间距、圆角与层级

- 间距基数 4pt，档位：4 / 8 / 12 / 16 / 20 / 24 / 32 / 48。页面左右边距 20，卡片内边距 16，内容区间隔 20–24，条目间隔 12。
- 圆角：卡片 20，控件（按钮/输入框）16，标签胶囊 999，sheet 顶部 28。（v4 原型 23/17 已收敛。）
- 层级：页面内容用背景色 + 分隔线分层；**阴影只给浮层**（sheet、迷你播放器、toast）。
- 全部可交互元素触控面积 ≥ 44×44pt。

## 5. 布局结构（极简单主页）

```
┌─────────────────────────────┐
│ 鲸鱼            任务  设置   │ ← 顶部：小标题 + 两个轻量入口
│                             │
│   （角色/状态小区，可选）      │ ← 小型品牌标识，不占主要阅读空间
│                             │
│   会话内容 / 空状态           │ ← 首次空状态仅一行："有什么想聊的？"
│   …消息、结果卡、确认入口…     │
│                             │
│ [+] [给鲸鱼发消息…    ] [语音] │ ← 底部统一输入区（唯一入口）
└─────────────────────────────┘
```

- 首页默认不出现：大角色卡、大语音按钮、功能卡片网格、固定流程标语、未知任务占位。
- 迷你播放器仅在音乐实际播放后出现在输入区上方。
- 任务/设置打开面板或次级页，返回继续原会话；草稿、候选、任务结果不因切换丢失。
- 键盘出现时隐藏次级内容，输入贴键盘上沿，确认动作保留在键盘上方；使用系统键盘布局，不写死高度。

## 6. 核心组件规范

### 6.1 统一输入区（最重要组件）
- 结构：附件"+"（44pt）｜输入框（bg-input，圆角16，占位"给鲸鱼发消息…"）｜语音按钮（44pt）。
- 有文字时：语音按钮切换为"发送"（accent 实色，text-on-accent 文字）。两个动作不同按钮/明确形态，不把同一按钮反复变形。
- 空文本提交不进入语音、不发起任务。
- 点击语音按需请求麦克风权限；进入语音保留草稿与同一会话。

### 6.2 对话气泡
- 用户消息：bg-surface-raised 圆角卡片，右对齐或缩进；助手消息：无底色自然段，正文 body。
- 普通回复以自然段呈现；地点、音乐、日程等结构化数据用专用卡，不在气泡里堆键值对。
- 消息出现动效：180–220ms 位移 6pt + 淡入。

### 6.3 结果卡（地点 / 日程 / 内容 / 音乐）
- 容器：bg-surface，圆角 20，内边距 16；标题 cardTitle，说明 secondary。
- 地点卡：名称、距离/范围口径、价格（body 字号）；价格未知显示"价格未知"文字而非留空；来源可展开。
- 日程卡：标题、日期、时刻、时区完整展示，字段可编辑（确认场景）。
- 内容卡：摘要、日期、行动项，标注来源与读取范围。
- 卡片不做整卡阴影，hover/选中用 accent-muted 底或描边。

### 6.4 确认 sheet
- 系统 sheet（顶部圆角 28，detent 可调），遮罩 bg-overlay。
- 内容：明确动作标题 + 完整参数（日期含时区）+ 可编辑字段；**只有一个主要确认按钮**（accent 实色）+ 次级取消（文字按钮）。
- 用户修改任一参数后旧确认失效，需重新确认。
- 打开/关闭 250–300ms，系统曲线。

### 6.5 语音页
- fullScreenCover：大角色 + 当前状态（倾听/处理/播报）+ 实时字幕 + 停止/静音/返回文字。
- 停止始终可达，与可滚动内容分离；返回文字保留同一会话与草稿。
- 波形绑定真实音频幅度；角色呼吸 3–4s、位移 ≤4pt；Reduce Motion 下关闭呼吸与漂浮。
- 停止播报 ≠ 撤销已写入；结束语音 ≠ 取消待确认任务；取消是明确业务动作。

### 6.6 状态与标签
- 任务状态：思考/执行/等待/完成/失败/已取消，用"图标 + 状态文字 + 色调"。
- 待核对（execution_unknown）：pending 色 + "查看记录"入口，**不提供盲目重做**。
- 错误：稳定错误代码映射文案 + 可操作下一步（授权/改地区/重试），保留原请求。
- 成功：精简结果卡 + 记录页可查；成功判定来自真实结果。

### 6.7 按钮
| 类型 | 样式 | 用途 |
|---|---|---|
| 主按钮 | accent 实色底 + text-on-accent，圆角16 | 发送、确认、开始 |
| 次按钮 | accent-muted 底 + accent 文字 | 次级动作、筛选 |
| 文字按钮 | accent 文字，无底 | 取消、查看来源 |
| 图标按钮 | 44pt 命中区，tertiary 色 | 任务、设置、附件、停止 |

### 6.8 迷你播放器
- bg-surface-raised，浮层阴影，圆角 20，位于输入区上方；封面小图 + 曲名 + 播放/暂停 + 下一首。
- 页面切换不中断；进入语音时按真实音频策略暂停/降低；用户主动暂停的音乐退出语音后不自动恢复。

## 7. 动效规范

| 交互 | 时长/节奏 | 说明 |
|---|---|---|
| 消息/结果出现 | 180–220ms，位移6pt+淡入 | 阅读位置连续 |
| sheet 开关 | 250–300ms | 临时层级，保留原会话 |
| 角色待机 | 3–4s 呼吸，位移≤4pt | 有生命感不抢文字 |
| 语音波形 | 真实幅度 | 禁止随机波形 |
| 完成 | 状态文字+小图标 | 成功来自真实结果 |
| 震动 | 仅选择/确认用系统 selection/success 反馈 | 不逐字逐条震动 |

Reduce Motion：关闭漂浮、光效、呼吸等连续装饰；保留文字与图标状态。无自动声音。

## 8. 无障碍要求（WCAG AA 最低线）

1. 对比度：正文 ≥4.5:1、大字 ≥3:1（当前配色全部达标并留余量）。
2. 动态字体：200% 放大下允许换行与纵向滚动，不截断关键信息。
3. VoiceOver：语义标签完整；状态变化有 announcement；结果卡按字段朗读。
4. 触控目标 ≥44×44pt；语音停止与内容滚动分离。
5. Reduce Motion、深浅色、大字、VoiceOver 验收用例见 12 号文档。

## 9. SwiftUI 映射与 Token 落地

| 设计模块 | SwiftUI 建议 | 状态来源 |
|---|---|---|
| 顶部入口 | NavigationLink / 轻量按钮 | 当前路由 |
| 会话 | ScrollView + LazyVStack | 会话消息 + TaskRecord |
| 统一输入区 | safeAreaInset | 草稿、键盘、InputMode |
| 结果卡 | 可复用数据视图 | 工具真实返回 |
| 确认 | sheet + detent | 当前有效 operationId |
| 语音 | fullScreenCover | 真实 ASR/Agent/TTS 阶段 |
| 偏好 | Form 分组列表 | 实际偏好与可观察授权 |
| 记录 | 日期分组列表 | 持久化操作日志摘要 |

Token 落地：以 tokens.json 为唯一取值来源，生成 `DesignTokens.swift`（Color/Font/Spacing 常量），原型与原生共同引用；原型示例数据、计时效果、状态栏与演示分支不迁移为业务逻辑。

## 10. 验收清单

- [ ] 主页只有底部一个可用语音入口，上方无可执行语音按钮（23 号验收 1）。
- [ ] 有草稿时"语音/发送"区分明确；点语音不发草稿（23 号验收 2）。
- [ ] 语音↔文字往返保留消息、候选、草稿（23 号验收 3）。
- [ ] 空白提交不进语音、不发起任务（23 号验收 4）。
- [ ] 状态均图标+文字+色调表达；深浅色、大字、VoiceOver、Reduce Motion 通过。
- [ ] 阴影只出现在浮层；卡片圆角 20、控件 16、触控 ≥44pt。
- [ ] 成功/失败/待核对文案来自真实状态，无计时器判定。
