# HTML 模拟版：iPhone 真机验收清单

版本：v0.6｜日期：2026-11-09｜对象：HTML 模拟版，不是原生 App

## 1. 验收边界

本轮真机验收只验证：页面在 iPhone Safari 的布局、输入、滚动、按钮、状态机与文案，以及网页到后端 DeepSeek 的真实文字链路。不要把本轮结果写成 EventKit、HealthKit、定位、MessageUI、MusicKit 或讯飞已通过。

必须分开记录两件事：`modelMode=deepseek` 表示自然语言由真实模型理解；`executionMode=mock` 表示提醒、日历、天气、健康、地点、导航、短信与音乐仍由 Mock 执行，没有写入真实系统或产生真实音频。

原生能力验收仍被工程缺失与 macOS/Xcode 条件阻断，见 `06_M0_工程盘点与执行基线.md`。

## 2. 环境准备

1. 电脑运行 `cd F:\VS_t\代号鲸鱼01\backend; node src/server.mjs`，确认 `http://127.0.0.1:8787/healthz` 为 `deepseek / mock`。
2. 电脑运行 `cd F:\VS_t\代号鲸鱼01\web; node serve.mjs`。
3. 手机与电脑连同一 Wi-Fi，访问 `http://<电脑局域网 IP>:8088`。
4. 或使用 GitHub Pages 地址；仅静态页面时只能验本地规则，不能验真实模型。
5. 记录：iPhone 型号、iOS 版本、Safari 版本、访问地址、后端模式、验收时间。

## 4. 视觉与可用性检查

- 顶栏与状态栏无重叠，安全区留白合理。
- 气泡、工具卡、结果条在 390pt 宽度下不溢出。
- 快捷指令可横向滚动，末尾不被永久截断。
- 长地名、长标题换行不撑破卡片。
- 深色模式不要求；如系统为深色，浅色页面仍应可读。
- 常用触控目标不小于约 44×44 pt；相邻目标不重叠。
