  • 无常驻底部导航条；任务 / 设置为顶部轻量入口，返回继续原会话。
  • 首次空状态只有一行问候，无大角色卡、无功能卡片网格、无固定标语。
  • 角色为小型品牌标识，仅语音 / 任务状态时成为视觉中心。
  • 底部唯一入口：附件 ＋ ／ 文字输入 ／ 语音；有文字时"语音"变为"发送"。
  • 空白提交不进入语音、不发起任务（23 号验收 4）。
  • 迷你播放器仅在音乐实际播放后出现，页面切换不中断。
  • 键盘出现时输入贴键盘上沿；全部触控目标 ≥ 44×44pt。

色彩体系

深色为默认主题，浅色为完整对等主题。状态以"图标 + 文字 + 色调"三重表达，不只用颜色。

✓ 已创建提醒 ◐ 待补充时间 ◎ 结果待核对 ✕ 定位权限已拒绝 ↗ 已打开地图

状态徽章：图标 + 文字 + 色调。错误必须附可操作下一步；待核对提供"查看记录"入口，不提供盲目重做。

字体体系

系统字体（SF Pro / 苹方），跟随动态字体，全部支持放大换行。正文 17pt 为基准，必要时间和金额不压小字。

对话与结果卡

普通回复以自然段呈现；结构化数据用专用卡。卡片圆角 20、内边距 16，无阴影；价格未知用文字说明而非留空。

按钮
