页面清单（10 个状态全覆盖）

  • 主页：空状态 + 内容建议 + 最近未完成，顶部 任务/设置 入口。
  • 找店对话：范围/预算条件持续可见，价格未知项明确标注，来源可查。
  • 内容摘要：勾选行动项后确认写入，不自动全量写入。
  • 语音：整屏覆盖，倾听/处理/播报三态，停止始终可达。
  • 音乐：正在播放 + 曲库列表；空曲库如实说明来源与条件。
  • 记录：日期分组，含待核对状态与"查看核实"路径。
  • 设置：偏好 + 能力授权（真实系统状态，拒绝不阻塞）。
  • 确认 Sheet：完整参数 + 唯一主确认，改参数即失效。

GLASS 视觉规则

  • 深度 = 渐变底 + 半透明层 + backdrop blur，文字始终有可读底层。
  • 主强调靛蓝 #5856D6（浅）/ #8B8AF0（深）；层级靠 blur 与透明度，不靠线框堆叠。
  • 圆角：卡 20 / 控件 16 / sheet 28；阴影只给浮层。
  • 原生用 ultraThinMaterial + availability 判断；不确定可读性就加厚材质。

交互铁律（23 号）

  • 底部统一输入是文字/附件/语音唯一入口；空白提交不进语音。
  • 语音↔文字保留同一会话与草稿；切页面不清任务。
  • 成功判定来自真实状态，待核对不提供盲目重做。
