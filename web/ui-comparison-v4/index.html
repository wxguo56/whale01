推荐 · 已加入B原型

底部统一输入

文字、附件和语音在同一输入区。语音切换始终可见，有文字时再出现发送动作，操作位置稳定。

备选结构

文字／语音分模式

显式选择模式，每次只显示当前输入方式。适合长语音，但切换多一步。

备选结构

语音优先

首页只有主要语音入口，文字作为次级入口。适合陪伴型体验，需要语音链路先足够稳定。

HOW TO CHOOSE

先选整体气质，再看每天用起来是否舒服。

主页决定第一印象，语音决定交流感受，结果和确认决定办事是否清楚。

A / 版式

耐看，擅长读与整理

大文字、编号和细线建立层次。适合频繁阅读、查询和管理事项。

B / 折光

科技感，擅长展示过程

用材质和空间区分状态。透明度与光效受到限制，保证文字清楚。

C / 涂鸦

有性格，擅长亲切交流

角色和纸张形成识别。装饰留在边缘，任务数据保持端正可读。
