哪些能直接做，哪些有条件？

把使用范围看清楚，避免期待落空。

需要你按需授权

日历、提醒、定位、音乐、麦克风、联系人等按功能申请。拒绝某项权限，只影响相应功能；能用手动地区或文字输入时提供替代方式。

价格与资料必须有来源

查不到价格就标未知，套餐不当人均。只有链接时先尝试取正文，未取得就不假装读过全文。范围搜索返回可取得的候选，不保证覆盖每一家店。

导航和发送有完成边界

导航完成指已打开地图，不代表已经抵达。短信／邮件由你在系统界面发送，结果依据系统回调；已发送不等于对方已读。

周期任务依赖可用数据

云端可运行已经配置的流程。手机关闭或后台时，不能保证随时读取最新手机日历和定位；通知也不保证精确到秒。语音主要是主动开启的前台会话。

天气、健康还要解决版本条件

此前核查的免费签名版禁用了 WeatherKit／HealthKit 路径。需要满足相应签名条件，或为天气接通并验收其他合法来源；健康还依赖实际授权和数据。三批任务完成，不会自动解除这些限制。

这些需要另行拓展

以下功能没有自动包含在本次完成范围内。每一项都写清目标、最小可交付和边界，不把“能跳转”说成“已打通”。

其他音乐 App P1 · 当前问题

现状：系统“音乐”资料库为空；手机里的歌曲在「汽水音乐」等第三方 App 的沙盒中，iOS 不允许鲸鱼直接读取。

最小可交付：① 从“文件”导入 mp3/m4a/wav 并用鲸鱼自己的播放器播放；② 系统音乐库有歌时用 MediaPlayer 读取；③ 对开放 URL scheme 的 App 只做播放/暂停/下一首，不列歌单。

边界：不读其他 App 私有缓存，不绕过 DRM；第三方 App 的完整曲库无法获得。

系统闹钟 / 计时器 P1

目标：创建一次性/重复闹钟和倒计时，到点由系统响铃。

最小可交付：iOS 26 使用 AlarmKit；创建、列出、取消本 App 的闹钟；锁定屏幕后仍能响。

边界：不改系统“就寝”计划；静音/专注模式下的响铃受系统设置影响，不冒充绝对保证。

小组件 / 灵动岛 P2

目标：桌面小组件显示今日提醒/最近任务；灵动岛显示进行中任务或播放。

最小可交付：先做只读小组件，再做一次任务从开始到结束的短时 Live Activity。

边界：刷新由系统调度，不保证秒级；免费签名版 App Group 受限，可能只能做静态占位。

邮箱收件箱与外部账号 P2

目标：读取最近邮件、摘要、起草回复。

最小可交付：先接一个邮箱（Gmail 或 Microsoft），只读最近 20 封；回复只进草稿，不自动发送。

边界：不保存邮箱密码；Token 加密存储；不绕过验证码/风控；不读取未授权文件夹。

Home 智能家居 P2

目标：控制 HomeKit 灯、开关、场景，读取温湿度/门锁状态。

最小可交付：列出家庭/房间/设备，执行开关与场景；温控与传感器后置。

边界：需要 HomeKit capability 和正式签名；免费签名大概率不可用；非 HomeKit 品牌需厂商云 API。

运行时生图 / 视频 / 3D P2

目标：对话中生成图片、短视频、3D 角色预览。

最小可交付：先接文生图 + 结果卡片 + 保存到相册；视频/3D 后置。

边界：需要生成服务账号与额度；内容需审核；不承诺实时；费用单独计算。

订餐 / 订位 / 购票 / 支付 P3

目标：找店、跳转订位/购票、整理订单信息。

最小可交付：信息整理 + 深链跳转 + 复制订单信息；有公开 API 的平台再接订位。

边界：不代付、不抢票、不存支付凭证、不绕过验证码；多数平台需要合作接口。

云端电脑与多 Bot P3

目标：云端长任务、多角色协作、跨设备继续。

最小可交付：单 Bot 任务队列 + 沙箱 + 结果回传 + 失败重试；多 Bot 只做显式编排。

边界：不在手机端跑多 Agent；不承诺手机关机后仍控制本机 App；成本与权限隔离先行。

建议顺序：本地音乐导入 → 系统闹钟 → 小组件 → 邮箱 → 智能家居 → 生图 → 订餐支付 → 云端多 Bot。

不作通用承诺：任意读取微信私有聊天、静默代发消息、全天后台唤醒、手机关闭后任意控制其他 App。

第一批

办事可靠

真定位、范围搜索、目标跟踪、身份校验、断网恢复、统一快捷入口。

第二批

能查、能说、能组合

公开检索、网页与价格、语音播报和打断、音乐协同、分享及组合场景。

第三批

记住习惯、持续服务

偏好记忆、已有事项管理、图片／PDF、流程复用、周期服务和新交互。
