# 代号鲸鱼01：HTML 模拟版

这是一个**纯前端交互模拟**，用于在真机验收前确认产品流程、状态机与文案。它不连接 EventKit、HealthKit、定位、MessageUI、DeepSeek 或讯飞，所有“成功”均为本地脚本模拟。

## 运行

```powershell
cd F:\VS_t\代号鲸鱼01\web
node serve.mjs
```

打开 <http://127.0.0.1:8088>。手机访问时，把 `127.0.0.1` 换成电脑的局域网 IP，并确认防火墙允许 8088 端口。

服务器默认监听 `0.0.0.0`，启动时会打印可用的 `phone access` 局域网地址。只在本机查看时可用：

```powershell
$env:HOST = "127.0.0.1"; node serve.mjs
```

当前电脑示例：<http://10.219.86.103:8088>（手机需与电脑同一 Wi-Fi；若打不开，请在 Windows 防火墙允许 Node.js 的专用网络访问）。

无构建步骤、无第三方依赖。

## 可以演示什么

页面按 iPhone 使用路径组织为四块，而不是单纯堆叠聊天示例：

| 页面 | 入口 | 观察点 |
|---|---|---|
| S01 助手首页 | 首次打开 | 鲸鱼角色、问候、天气／日程／运动摘要、常用入口、开始对话 |
| S02 对话与执行 | 首页「开始对话」或摘要卡 | 输入、语音、快捷指令、任务卡、追问、执行状态 |
| S03 操作确认 | 任务卡「查看并确认」 | 原生 sheet、字段核对、修改后旧确认失效、确认后写入 |
| S04 设置与能力 | 右上角设置按钮 | 日历／提醒／运动／定位状态、语音广播、隐私与演示场景入口 |

| 场景 | 操作 | 观察点 |
|---|---|---|
| 首页入口 | 点「开始对话」、摘要卡或常用按钮 | 正确切换到对话页；摘要卡会带入对应问题 |
| 提醒闭环 | 输入「明天下午三点提醒我取快递」 | 解析为 11月10日 15:00，先出工具卡；打开 S03 确认后才写入并显示记录 ID |
| 确认前修改 | 工具卡「查看并确认」→「修改」→ 保存 | 卡片同步新参数，提示旧确认失效，仍可重新确认 |
| 无日期待办 | 输入「创建待办：买牛奶」 | 不补造截止时间 |
| 缺少时刻 | 输入「明天提醒我取快递」 | 追问具体时间，不调用工具 |
| 上午下午歧义 | 输入「明天三点提醒我取快递」 | 追问上午/下午 |
| 权限拒绝 | 场景面板把提醒权限设为「拒绝」后重试 | 不写入，解释设置入口，不反复弹授权 |
| 断网回传失败 | 先在线出确认卡，再切「断网」后确认 | 本地已写入，但标记待回传；恢复网络后只回传一次 |
| 重复提交 | 写操作成功后点「重复提交上次写操作」 | 返回已去重，提醒数量不增加 |
| 日历查询与创建 | 「查明天下午的安排」→「安排 16:00 健身」 | 查询结果、空档、确认后创建日程 |
| 天气 | 「明天天气」；「朝阳天气」；「下周天气」 | 正常预报、同名地区选择、超范围拒绝编造 |
| 运动摘要 | 「今天运动了多少」 | 默认无数据，明确区分“无数据/无权限”，不报 0 |
| 地点导航 | 「附近咖啡店」→ 选第 2 家 →「带我去」 | 使用第二个候选；只反馈已交接，不声称抵达 |
| 内容总结 | 「把这段分享总结成三点」 | 基于正文；只有链接时明确不能假装读过 |
| 短信草稿 | 「给张三准备一条短信」 | 本地联系人候选；只说草稿已准备，不声称已发送 |
| 模型循环上限 | 场景面板「模拟模型循环上限」 | 3 批后停止，保留已完成步骤并说明未完成 |

## 场景面板

右上角设置按钮进入 S04，再点「打开演示场景与权限开关」，可切换：固定/真实时钟、时区、提醒权限、网络、健康数据、自动确认。开关状态保存在 `localStorage`。

事件面板按 `contracts/v1/events.v1.json` 的 `turn.started`、`tool.requested`、`tool.confirmation_required`、`tool.result`、`turn.completed`、`turn.limit_reached` 展示，可用于核对产品与工程是否理解一致。

## 文件

- `index.html`：S01 首页、S02 对话、S03 确认 sheet、S04 设置与诊断抽屉
- `styles.css`：iPhone 外壳、四页样式、响应式布局与确认 sheet
- `app.js`：页面切换、意图路由、日期解析、确认/取消/修改、幂等/断网恢复、事件日志
- `serve.mjs`：零依赖静态服务器
- `真机验收清单.md`：iPhone 上的验收步骤与记录模板

## 已知限制

- 不是 iOS App，不能验证 EventKit、HealthKit、定位、MessageUI、Siri 或推送。
- 未接 DeepSeek；意图识别是规则匹配，只覆盖演示句式。
- 未接讯飞；麦克风按钮为固定 1.9 秒的模拟识别。
- 天气、日历、地点、健康数据均为固定 Mock，不代表真实供应商能力。
- 时区换算覆盖常见场景，夏令时边界仍需真机与时区库验证。
