# 代号鲸鱼01：HTML 模拟版

这是一个**前端交互模拟 + 可选真实模型后端**，用于在真机验收前确认产品流程、状态机与文案。连接后端时，自然语言由真实 DeepSeek 理解；提醒、日历、天气、健康、定位、短信与音乐仍由后端 Mock 执行，不写入真实系统，也不产生真实音频。未连接后端时回退到本地规则演示。

## 运行

```powershell
cd F:\VS_t\代号鲸鱼01\backend
node src/server.mjs

cd F:\VS_t\代号鲸鱼01\web
node serve.mjs
```

打开 <http://127.0.0.1:8088>。手机访问时，把 `127.0.0.1` 换成电脑的局域网 IP，并确认防火墙允许 8088 端口。

网页默认连接同主机的 `8787` 端口后端，因此手机上访问 `http://<电脑局域网 IP>:8088` 时会自动请求 `http://<同一 IP>:8787`。后端需监听 `0.0.0.0`，或至少允许局域网访问。

## 模型与执行边界

设置页「对话后端」会同时显示两项事实：

| 字段 | 正常值 | 含义 |
|---|---|---|
| 当前模式 | `DeepSeek 真实模型` | 自然语言确实到达真实模型 |
| 模型 | `deepseek-chat` | 当前上游模型 |
| 执行 | `Mock 模拟` | 工具结果由后端 Mock 返回，不写真实系统 |

不要把「DeepSeek 真实模型」理解为「提醒、日历、音乐已真实执行」。两者是独立维度。

- 连接：点设置页「连接后端」；成功后可发送自然语言。
- 新会话：点「开启新会话」重置后端上下文，避免旧候选与任务带入。
- 断开：点「断开后端，回到本地演示」，使用本地规则分支。
- 失败：模型或后端失败时显示错误与重试入口，不静默切回本地规则冒充成功。

### 流式与断网恢复

- 对话默认使用 `text/event-stream`：模型正文逐段出现，工具参数由服务端按分片拼接后再执行。
- 如果事件流在 `turn.started` 之后中断，页面不会重发写操作，而是用 `GET /v1/turns/{turnId}` 轮询后台快照，恢复出完整结果；状态栏会显示「连接中断，正在恢复…」。
- 如果连接在 `turn.started` 之前就失败，只有后端不可达或 429/5xx 才自动重试；其余情况保留输入并提供手动重试，避免重复创建提醒。

### GitHub Pages

仓库内已提供 `.github/workflows/pages.yml`，推送 `web/` 变更即可部署静态演示。但当前 `wxguo56/whale01` 是私有仓库，GitHub 返回「当前套餐不支持私有仓库 Pages」；需将仓库公开或升级套餐后再启用。仅静态页面时只能验本地规则，真实模型仍需可访问的后端。

服务器默认监听 `0.0.0.0`，启动时会打印可用的 `phone access` 局域网地址。只在本机查看时可用：

```powershell
$env:HOST = "127.0.0.1"; node serve.mjs
```

当前电脑示例：<http://10.219.86.103:8088>（手机需与电脑同一 Wi-Fi；若打不开，请在 Windows 防火墙允许 Node.js 的专用网络访问）。

无构建步骤、无第三方依赖。

## 可以演示什么

页面按 iPhone 使用路径组织为四块，而不是单纯堆叠聊天示例：

| 页面 | 入口 | 观察点 |
|---|---|---|
| S01 助手首页 | 首次打开 | 鲸鱼角色、问候、天气／日程／运动摘要、常用入口、开始对话 |
| S02 对话与执行 | 首页「开始对话」或摘要卡 | 输入、语音、快捷指令、任务卡、追问、音乐模拟与执行状态 |
| S03 操作确认 | 任务卡「查看并确认」 | 原生 sheet、字段核对、修改后旧确认失效、确认后写入 |
| S04 设置与能力 | 右上角设置按钮 | 日历／提醒／运动／定位状态、语音广播、隐私与演示场景入口 |

| 场景 | 操作 | 观察点 |
|---|---|---|
| 首页入口 | 点「开始对话」、摘要卡或常用按钮 | 正确切换到对话页；摘要卡会带入对应问题 |
| 提醒闭环 | 输入「明天下午三点提醒我取快递」 | 解析为 11月10日 15:00，先出工具卡；打开 S03 确认后才写入并显示记录 ID |
| 确认前修改 | 工具卡「查看并确认」→「修改」→ 保存 | 旧卡标记「已作废」，生成新的 `operationId` 与新确认卡；旧确认不能执行新参数 |
| 无日期待办 | 输入「创建待办：买牛奶」 | 不补造截止时间 |
| 缺少时刻 | 输入「明天提醒我取快递」→「下午三点」 | 保留待补任务并恢复原提醒，得到 11月10日 15:00 的确认卡；取消后补时间不会恢复 |
| 上午下午歧义 | 输入「明天三点提醒我取快递」→「下午」 | 同一待补机制补全为 15:00，不要求重述整句 |
| 权限分离 | 场景面板分别切换提醒、日历读取、日历写入、音乐库权限 | 各能力互不绑定；无读取权限不伪造日程，写入仍走明确入口 |
| 断网回传失败 | 先在线出确认卡，再切「断网」后确认 | 本地已写入，但标记待回传；恢复网络后只回传一次 |
| 重复提交 | 写操作成功后点「重复提交上次写操作」 | 返回已去重，提醒数量不增加 |
| 日历查询与创建 | 「查明天下午的安排」→「安排 16:00 健身」 | 查询结果、空档、确认后创建日程 |
| 天气 | 「明天天气」；「朝阳天气」；「下周天气」 | 正常预报、同名地区选择、超范围拒绝编造 |
| 运动摘要 | 「今天运动了多少」 | 默认无数据，明确区分“无数据/无权限”，不报 0 |
| 地点导航 | 「附近咖啡店」→ 选第 2 家 →「带我去」 | 使用第二个候选；只反馈已交接，不声称抵达 |
| 内容总结 | 「把这段分享总结成三点」 | 基于正文；只有链接时明确不能假装读过 |
| 短信草稿 | 「给张三准备一条短信」 | 本地联系人候选；只说草稿已准备，不声称已发送 |
| 音乐（模拟） | 「我想听歌」→ 选曲 → 暂停／继续／下一首 | 展示演示曲库与模拟播放状态；明确没有真实音源，不读取 iPhone 音乐库 |
| 歌名搜索 | 「播放周杰伦」 | 模拟曲库无匹配时准确说明，不转向付费云端，不伪造音源 |
| 页面历史手势 | 首页→对话→设置，左滑两次再右滑两次 | 左滑返回、右滑前进；卡片按钮上也能滑动，滑动后不会触发按钮；历史切换保留消息与输入；输入框、横向控件和弹层内不拦截 |
| 模型循环上限 | 场景面板「模拟模型循环上限」 | 3 批后停止，保留已完成步骤并说明未完成 |

## 场景面板

右上角设置按钮进入 S04，再点「打开演示场景与权限开关」，可切换：固定/真实时钟、时区、提醒事项权限、日历读取、日历写入、音乐库、网络、健康数据（无数据／有数据／读取中／读取失败）和自动确认。开关状态保存在 `localStorage`。

事件面板按 `contracts/v1/events.v1.json` 的 `turn.started`、`tool.requested`、`tool.confirmation_required`、`tool.result`、`turn.completed`、`turn.limit_reached` 展示，可用于核对产品与工程是否理解一致。

## 文件

- `index.html`：S01 首页、S02 对话、S03 确认 sheet、S04 设置与诊断抽屉
- `styles.css`：iPhone 外壳、四页样式、响应式布局与确认 sheet
- `app.js`：页面历史与手势、意图路由、待补任务上下文、日期解析、权限拆分、确认/取消/修改、操作身份、幂等/断网恢复、音乐模拟与事件日志
- `serve.mjs`：零依赖静态服务器
- `真机验收清单.md`：iPhone 上的验收步骤与记录模板

## 已知限制

- 不是 iOS App，不能验证 EventKit、HealthKit、定位、MessageUI、Siri 或推送。
- 前端不持有 API Key；真实模型必须经本地后端连接，后端配置见 `../backend/README.md`。
- 连接后端后，意图理解为真实 DeepSeek，但工具执行仍是 Mock；未连接时本地规则只覆盖演示句式。
- 未接讯飞；麦克风按钮为固定 1.9 秒的模拟识别。
- 天气、日历、地点、健康数据均为固定 Mock，不代表真实供应商能力。
- 音乐只有模拟曲库和模拟播放状态，没有真实音频文件，也不能读取 iPhone 音乐库。
- 手势已在 390×844 浏览器视口用触控事件验证，包括从卡片按钮起手与滑动后的点击抑制；iOS Safari 边缘返回手势与真机触感仍需 H30–H32 验收。
- 真实模型连接、失败不回退、新会话与提醒计数同步，按 `真机验收清单.md` H33–H39 验收。
- 时区换算覆盖常见场景，夏令时边界仍需真机与时区库验证。
