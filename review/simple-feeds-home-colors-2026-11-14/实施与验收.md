# 0.7.2 · 统一资讯与彩色入口恢复

日期：2026-11-14。用户确认助手首页六张彩色卡片、发现顶部六个标签两组都恢复；新闻与 AI 科技不再分分类，底部发现与待办对调。

| 用户要求 | 实施行为 |
|---|---|
| 新闻直接显示全部 | 删除国内/国际/军事/科技/汽车分类栏与分类滑动；列表使用频道全部资讯，仍支持下拉刷新和详情阅读 |
| AI 科技不分分类 | 删除游戏应用/程序开发/游戏科技/厂商动态分类栏；同一列表展示通过原有内容质量校验的频道资讯 |
| 删除“更多动态，公开 RSS” | 移除文章卡片前的标题与说明，不留空白占位；每篇来源信息继续显示 |
| 删除游戏说明 | 删除游戏页头部“游戏媒体资讯 · App Store 榜单”文字；游戏资讯、Steam 与排行榜功能保留 |
| 首页原有卡片布局与颜色 | 恢复 AI科技、A股自选、游戏动态、我的音乐、时事新闻、热榜六张卡片，两列三行；替代本轮前的三个统一色快捷按钮 |
| 发现频道标签配色 | 六个频道沿用旧版入口的青绿、蓝绿、橙金、紫粉、青蓝、珊瑚红渐变；紧凑圆角标签，独立频道颜色与柔和阴影 |
| 底部导航对调 | 助手／发现／待办；保存的主栏使用语义 ID，不因位置对调跳到错误页面 |
| 固定框架 | 发现标题、频道条、底部系统主栏固定；仅中间内容切换 |

旧版保存的 AI/新闻分类在初始化时清理；这两个频道的分类选择兼容入口回落“全部”，不再通过横向手势切换隐藏分类。音乐播放、草稿、待确认操作、权限和模型链路没有业务改动。原有可编辑快捷操作偏好数据保留；首页按用户选择恢复固定六频道卡片。

六频道渐变沿用旧版色相，文字下增加统一暗色承托；白字对比度的最亮渐变端点最低 4.69:1。大字号首页改为单列，发现标签可横向滚动；减少动态和减少透明度设置继续支持。
