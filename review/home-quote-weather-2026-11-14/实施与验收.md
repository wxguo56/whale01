# 0.7.3 · 顶部每日一句与日期天气卡片

日期：2026-11-14。用户要求去掉昵称问候、“有一件事需要核对”、独立“天气暂未更新”条及 BOSS 问候；将天气放到日期卡片，最上方增加名句和积极鼓励。

| 要求 | 实施 |
|---|---|
| 去掉昵称问候 | 首页移除“你好，昵称”和“今天想做点什么”；个人资料数据保留 |
| 去掉核对卡片 | 首页移除旧任务核对及待确认摘要卡片；对话确认 Sheet 和执行记录入口保留，未删除 pending 或任务数据 |
| 日期加入天气 | 日期/日程卡片中显示所在地、天气描述、温度；点击查看天气详情 |
| 去掉独立天气标签 | 删除原天气条；未知/未授权时在日期卡片内提供查看天气，已授权但未取得数据时提供刷新；不编造温度 |
| 去掉 BOSS 问候 | 每日一句只显示正文，不再带 BOSS 和早上好/下午好等开场 |
| 顶部正能量标签 | 每日一句位于首页内容最上方，使用玻璃卡片、柔和阴影；默认两行，可展开，大字号显示全文 |
| 句库 | 40 条沿用的经典名句与 80 条无人物署名的原创鼓励，替换旧调侃及不确定出处的现代名言；共 120 条，每日四个六小时时段，30 天不重复 |

首页顺序为每日一句 → 日期/天气/今天安排 → 播放状态（有曲目时）→ 六个彩色入口。底部保持助手／发现／待办；字号缩放、减少动态和减少透明度仍支持。首页显示每日一句的设置保留。
