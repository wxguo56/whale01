## 增量 Build 47：输入时聊天列表不再从头重刷

### 根因
- 输入框草稿直接存在 `AppModel` 的 `@Published input` 上，每敲一个字都会让 `RootView`、横向分页容器和消息列表整体重新求值，长列表就会出现“从顶部重新刷一遍”的观感。
- 列表滚动依赖 `messages.count` 变化后 `scrollTo` 最后一条，没有稳定的底部锚点；键盘出现、容器高度变化时容易重新定位。

### 改动
1. 草稿移到 `ConversationSurface` 的本地 `@State`，输入过程不再触发 `AppModel`，横向分页容器也不会跟着重排。
2. 列表增加底部锚点 `conversationBottom`，改用 `defaultScrollAnchor(.bottom)`，内容变化时滚到锚点；首次进入直接停在最新消息。
3. 键盘弹出期间禁用横向分页滑动，避免页面级重排带动列表跳动。
4. 删除 `AppModel.input`、`preparePrompt`、`send()` 这三个只为旧输入框服务的成员。

## 增量 Build 48：输入框高度不再顶动消息列表

### 根因
- `TextField(axis: .vertical)` 配合 `lineLimit(1...4)` 会随草稿内容自动增高。中文拼音输入法的标记文本（候选词）在 1 行与 2 行之间切换时，输入栏高度反复变化，列表被反复挤压。
- `.defaultScrollAnchor(.bottom)` 会在每次布局重锚定，进一步放大了这种上下跳动。

### 改动
1. 输入栏拆成独立子视图 `ConversationComposer`，草稿只留在子视图本地 `@State`。
2. 输入框改为单行固定高度 `TextField` + `.lineLimit(1)` + `.frame(height: 22)`，不再随文字增高。
3. 删除 `.defaultScrollAnchor(.bottom)`，保留底部锚点与内容变化时的显式滚动。
4. 增加 `.scrollBounceBehavior(.basedOnSize)`。

## 增量 Build 50：把键盘与横向分页彻底解耦

### 根因
- 横向分页容器位于 `GeometryReader` 内，键盘弹出时根视图安全区收缩，三页的高度同时变化；中文输入法候选栏高度变化会重复触发这一过程，页面内容的纵向位置被反复重算，表现为输入时列表上下抖刷。
- 输入框外层还挂了 `.scrollDisabled(keyboardVisible)`，键盘通知每次变化都会参与页面级状态更新；输入框右侧“收起键盘”按钮又是按 `focused` 动态插入/移除，聚焦状态变化会让输入行宽度重排。
- 只把草稿搬出 `AppModel`、只固定输入框高度，都没有切断“键盘 → 分页容器 → 消息列表”的重排链路。

### 改动
1. 新增 `KeyboardObserver`，用 `keyboardWillChangeFrameNotification` 读取键盘在窗口坐标中的真实顶边，不再依赖 `keyboardWillShow/Hide` 的布尔状态。
2. 对话页激活时，根视图对键盘安全区使用 `.ignoresSafeArea(.keyboard, edges: .bottom)`，横向分页容器高度在键盘弹出/候选栏变化时保持不变。
3. 对话页自行测量页面底边与键盘顶边，只给输入栏加精确的底部内边距；列表视口不再因键盘动画整页重算。
4. 首次弹出键盘时输入栏跟随键盘动画上移；候选栏变化、交互式收起时直接跟随键盘帧，不叠加动画队列。
5. “收起键盘”按钮改为固定占位，仅切换透明度与可点击性，输入框宽度不再因聚焦状态变化。
6. 键盘高度变化时只在主线程异步把列表钉回底部，不做动画滚动。

## 增量 Build 51：键盘动画结束后重新钉住最新消息

### 根因
- Build 50 把键盘和分页容器解耦后，输入栏的上移是有动画的；列表视口在动画过程中逐步变矮，只在动画开始时滚动一次，可能停在旧的高度，导致最新一条消息被输入栏挡住。

## 增量 Build 52/53：输入栏移出横向分页，聊天内容可复制

### 根因（重新定位）
- Build 51 虽然让分页容器忽略了键盘安全区，但输入框仍然在横向分页 `ScrollView` 的内容里。UIKit/SwiftUI 为了让聚焦的输入框可见，会让最近的滚动容器调整位置；在分页容器里就表现为整页上下被带着走。
- 只改键盘安全区、只固定输入框高度，都无法彻底切断“聚焦输入框 → 分页容器滚动”的路径。
- 另一个独立缺陷：消息文本没有开启选择，也没有复制入口。

### 改动
1. 新增独立的 `ConversationComposerBar`，放到 `RootView` 的 `ZStack` 底部、横向分页容器之外。输入框不再是分页滚动容器的子视图。
2. 对话页仍让分页容器忽略键盘，输入栏用键盘真实顶边做底部偏移；分页高度在输入过程中保持不变。
3. 消息列表的底部锚点改成包含输入栏预留高度与键盘高度的空白区，`scrollTo` 到底时最新消息停在输入栏上方，而不是被输入栏盖住。
4. 草稿、语音、照片/文件识别状态全部留在输入栏自身；输入过程不再触发分页或消息列表重算。
5. 消息支持系统文本选择：长按消息气泡可直接选中复制；消息右键/长按菜单新增“复制文字”；助手回复旁新增复制按钮。
