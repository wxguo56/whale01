## 已完成
1. 聊天历史、操作记录、任务快照持久化；重启后恢复显示。
2. 提醒与日程支持查询、修改、标记完成、删除；修改前要求定位已有记录。
3. 记忆偏好支持读取、保存、删除；设置页可管理，偏好注入本机模型提示词。
4. 网页搜索与正文读取、图片/PDF OCR 导入；搜索结果与 OCR 文本明确作为资料，不作为指令。
5. 工具契约、App 内置工具目录、后端能力表、提示词与 mock 执行同步。
6. 后端自动化测试 74 项全部通过；macOS 模拟器编译与原生单测通过。
7. 图片识别改为按文件内容判断 PNG/HEIC/JPEG，不再依赖临时文件扩展名。
8. 照片读取失败与模型网络失败分别给出可执行提示；超时和连接中断自动重试一次。
9. 新增 `find_free_slots`：读取真实日历，结合工作时窗、缓冲时间与全天事件计算候选空档；只读，不写入。
10. “查日历 → 找空档 → 展示候选 → 用户选定 → 生成日程预览 → 原生确认写入”组合流程已闭环，后端测试覆盖确认前不写入。
11. 同名提醒返回 `ambiguous_reminder`，不再自动修改第一条；错误信息列出时间、列表与 recordId。
12. 同名联系人或同一联系人多号码返回 `ambiguous_contact`，候选号码/邮箱脱敏展示，不再自动取第一个。
13. 旧确认卡校验 toolCallId 与 operationId；失效卡不执行、不提交，并明确提示重新发起。
14. 工具结果先写入本地 outbox；网络失败不丢弃结果，重启或回到前台时先查任务快照再续传，避免服务端已处理时重复提交。
15. 提醒/日程的更新与删除纳入执行中未知状态核对；删除以对象是否仍存在判定，修改无法确认时如实报告未知，不诱导重试。
16. 本机模型历史按 assistant tool_calls 与 tool 结果配对裁剪，孤儿工具消息和未完成调用块被丢弃；重复回传的 toolCallId 不再写入历史。
17. 周期规则支持每天／每 N 天、每周／每 N 周（可指定周一至周日）、每月、每年，并支持按次数或截止时间结束。
18. 周期规则已贯通工具契约、后端 Mock、EventKit 写入、工具结果摘要与模型提示词；周期提醒缺少具体开始时间时明确拒绝。
19. 周期结束条件统一使用 EventKit 原生初始化器，修复 Swift 编译问题。
20. 新增 `search_merchant_prices`：按商户名搜索公开网页并读取正文，抽取人均、套餐、标价等价格线索；返回来源 URL、取得时间和分店匹配程度，`verified` 恒为 false，不把品牌价冒充分店报价。
21. 价格证据接入任务缺口：有证据且分店匹配时移除“取得可核对的价格来源”；分店未匹配时保留“核对价格对应的分店”；无证据时不把缺口当作已补齐。
22. 新增 `get_current_location`：读取手机真实定位并反向解析省、市、区和街道，回答“我在哪／当前位置”；地址解析失败时只返回坐标与精度，不猜城市。
23. 定位改为持续取样 10 秒，优先采用更准的位置；首次定位精度差不再立刻失败，超时返回当前最佳点并标明精度。
24. 后端默认模式改为 fail-closed：`MODEL_MODE` 默认 deepseek、`EXECUTION_MODE` 默认 ios；只有显式设置 `EXECUTION_MODE=mock` 才进入测试模拟。
25. HTTP 接口不再在 Mock 模型模式下自动确认写操作；`autoConfirm` 默认 false，写操作必须经过界面确认。
26. 云后端处于 Mock 执行模式时，App 不再只显示警告，而是直接阻止发送，避免把模拟位置、模拟音乐或模拟写入当成真实结果。
27. 真实执行模式下 `summarize_shared_content` 不再由 Mock 执行器返回模拟摘要；能力表标记为未实现，模型改为直接基于本轮提供的分享正文总结。
28. 新增“回家／导航回家”真实数据守卫：没有详细家庭地址时直接追问，不把“家”当关键词搜索；有地址时先解析真实地点，再交给地图。`open_navigation` 只表示已交接地图，不表示路线已规划或已经到家。
29. 本地直连引擎增加真实数据意图守卫：当前位置、天气、附近地点、导航请求若模型只回文字而未取得成功工具结果，最终回复会被替换为“没有拿到真实数据”，不保留编造的结论。失败的定位/搜索不算成功工具结果。
30. 修正天气提示词“以本轮模拟结果为事实”的错误表述；空档查询默认 09:00–21:00 时要求明确说明窗口，不把结果说成全天有空。
31. 导航意图不再把“把照片发过去”这类普通“过去”误判成导航；新增回归测试。

- 侧载免费签名构建不包含 HealthKit / WeatherKit 能力，`get_weather` 与 `get_activity_summary` 会明确返回不可用，不会假装查询成功。
- 通讯录与短信/邮件草稿已接入真实 Contacts 与 MessageUI；发送结果仍以系统界面回调为准。
- 组合 Skill 已完成“空档安排”；商户价格已接入公开网页证据链路，但没有大众点评／美团等实时商家 API，价格不是实时报价，分店匹配需按 `branchMatch` 如实说明。
- 周期提醒/日程已接入 EventKit 原生重复规则；后台定时主动服务、保存可复用流程尚未实现，不能宣称具备后台 Agent 能力。
- 当前位置需要系统定位权限和定位服务开启；免费签名构建可以定位，但天气／健康仍受免费签名能力限制。
