# UI-1 实施记录：GLASS 分页导航

日期：2026-11-10｜版本：0.5.0 (30)｜方向：28 号 v2.0 导航 + GLASS 视觉

## 已落地

- 移除常驻底部 TabView，改为三页横向分页：主页对话 / 任务与记录 / 设置。
- 原生分页：`ScrollView(.horizontal)` + `scrollTargetLayout` + `scrollTargetBehavior(.paging)` + `scrollPosition(id:)`，拖动实时跟手、松手吸附，翻页触发 selection 反馈。
- 主页顶部提供任务、设置入口；记录与设置页提供回到对话入口。
- 主页去掉大角色卡与功能宫格，改为轻问候、内容 chips、最近一次结果卡与底部统一输入区。
- 语音入口收敛为输入区麦克风；不再有第二个“和鲸鱼说话”按钮。
- 三页共用同一 GLASS 渐变底，避免翻页时背景断层；卡片改为 `.ultraThinMaterial` + 白色 hairline + 轻投影，Reduce Transparency 回退实色 `#E3E9F5 / #232A42`。
- 设置页由 List 改为玻璃卡片分组，合并外观、语音、权限、性能、开发与关于；删除重复的 ProfileView。
- 迷你播放器改为全局浮层，不随页面横滑，页面切换不中断。
- 对话详情、设置二级页、sheet 打开时禁用分页手势，避免误滑。
- 头部玻璃按钮与迷你播放器的播放／下一首触控区统一为 44×44pt。
- 地点搜索结果不再只以文字列表呈现：`search_places` 结果附带经纬度，对话内渲染 MapKit 地图卡，直接标记候选地点，并可一次交给系统地图。
- 对话页顶栏改为可见的 `.regularMaterial`，输入条改为 `.regularMaterial` 并延伸到底部安全区，避免正文与状态栏、输入区混在一起。
- 助手正文按行内 Markdown 渲染，去掉模型输出里的 `**` 记号；朗读、麦克风、发送、收起键盘按钮补到 44pt。

## 材质说明

GLASS 是设计方向：渐变底、半透明层、hairline 与浮层阴影。原生实现使用系统 `Material`（`.ultraThinMaterial` / `.thinMaterial`），并按 Reduce Transparency 回退实色；不把 CSS `blur(22px)` 当成可精确复刻的参数。Liquid Glass 是 iOS 26 SDK 的新材质 API，本工程以 iOS 17 为部署基线、CI 使用旧 SDK，因此不宣称已接入。
