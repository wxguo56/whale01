# UI 方案可执行性评估

日期：2026-11-10｜评审对象：`28_iOS原生全系统UI与动效设计.md`（v2.0）、`28_GLASS通透全页面设计方案.md`、`design/ios-system-v7/`

## 结论

可以执行。文档具备派工条件：有信息架构、20 个界面清单、状态矩阵、组件到原生 API 的映射、动效约束、验收门槛和数据绑定说明；原型资源也能正常加载（`http://127.0.0.1:8088/ios-system-v7/` 返回 200，CSS/JS/画板均 200）。

但有两处必须先裁决，否则执行者会返工或做出与规范相反的东西。

## 必须先定的一：三标签还是单主页

- v2.0 第 1 节、第 11 节验收门槛 1 明确要求：没有常驻三标签导航、没有功能宫格、没有大角色卡；任务与设置是顶部入口。
- 当前已安装的 0.4.9 恰好是三标签（对话／记录／我的）＋左右滑动切换，这是上一轮按负责人要求实现的。
- 两者不能同时成立。可选：
  - A（推荐，若 v2.0 是定稿）：删除 TabView，记录与设置改为主页顶部入口，左右滑切换 Tab 一并移除。
  - B：三标签保留为过渡壳，只替换视觉与对话体验；明确接受与门槛 1 冲突。
  - C：三标签保留但去掉滑动，仅作为导航；仍需负责人书面豁免门槛 1。

未裁决前，不应改 `RootView` 的导航结构。

## 可执行性逐项判断

| 项 | 判断 | 说明 |
|---|---|---|
| 页面结构（20 屏） | 可执行 | NavigationStack／List／Form／sheet／confirmationDialog 均有直接映射 |
| 统一输入区 | 可执行 | `safeAreaInset` 固定底部输入；需重排现有 ChatView 输入栏 |
| 语音内联到主页 | 可执行，但有回归成本 | 现在是 460pt sheet；改为同一主页状态机后，需重测停止自动发送、打断、转文字、取消四条路径 |
| 真实音频幅度 | 需新增能力 | 现有波形是装饰动画；要接 AVAudioEngine／录音缓冲区 RMS，否则违反方案「不随机波形冒充」 |
| 任务与记录 | 需新增持久化展示 | 现有只有内存中最近 12 条 `recentActions`；方案要求 TaskRecord 分组、待核对、恢复 |
| 确认表单 | 可执行 | 现有 ConfirmationSheet 已有参数摘要，可改为 Form＋toolbar 单主操作 |
| 天气／地点结果卡 | 可执行 | 现有 WeatherExecutor／LocationExecutor 返回结构可直接驱动 |
| 音乐迷你播放器 | 可执行 | 已有 PlaybackSnapshot 与迷你条，需改成方案中的收拢／展开 |
| 内容摘要 S12 | 能力未接通 | 分享扩展已有，但正文抓取／PDF／OCR 未实现，只能做如实空态 |
| 日程空档 S07 | 能力未接通 | 目前只有日历读写，没有空闲计算；不能承诺「真正空闲」 |
| 记忆 S14 | 未实现 | 仅设计；需要可编辑结构化存储 |
| 周期服务 S17 | 未实现 | 需要后端流程与通知，属后续里程碑 |
| 健康 S19 | 受限 | 免费签名构建禁用 HealthKit，只能显示不可用 |
| 讯飞 TTS S20 | 未实现 | 当前是系统中文语音，设置页不得写成讯飞合成 |

## 技术风险

1. 改导航结构会推翻刚验证过的三标签与侧滑，需整体回归。
2. 大量材质／模糊在滚动列表中的帧率未测；方案要求 Reduce Transparency 降级。
3. iOS 17 基线与 iOS 26 材质差异需要 availability 分支。
4. 画板是模型生成位图，细字与图标可能变形，只能作视觉参考，不能切图。
5. 20 屏里至少 6 屏依赖未接通能力，若直接做成可点页面会被误认为已实现。

## 建议实施顺序

| 阶段 | 内容 | 估算 |
|---|---|---|
| UI-1 | 单主页壳、顶部任务／设置、统一输入、对话与结果容器 | 2–3 天 |
| UI-2 | 任务记录、确认表单、未知结果与恢复 | 2–3 天 |
| UI-3 | 天气／地点结果卡、地点详情、音乐迷你播放器 | 2–3 天 |
| UI-4 | 语音内联、真实幅度、播报状态、打断回归 | 2 天 |
| UI-5 | 设置、偏好、权限、周期服务（按能力开放） | 2 天 |
| 回归 | 真机矩阵、Dynamic Type、VoiceOver、Reduce Motion | 2 天 |

合计约 10–13 个工作日；UI-1 完成即可出可安装版本验证方向。

## 建议的第一刀

保留现有执行器、OperationLedger、LocalAgentEngine 不动，只替换表现层；先交付 S01／S02／S03／S05／S06，其余页面以「能力未接通」空态占位。每步出递增 Build 与真机截图，避免一次性大改后无法定位回归。
