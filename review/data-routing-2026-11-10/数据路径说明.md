## 功能逐项

### D01 普通文字对话 / 解释 / 写作

对话入口：通常调用 deepseek-chat

直接入口：当前普通对话入口仍通过模型

来源：DeepSeek Chat Completions

网络：Wi-Fi 或移动数据均可访问模型

离线：新回复需要联网；可查看本地已有记录

模型数据：用户输入、近期会话上下文、设备时间/时区、权限状态、工具定义和已保存偏好

依据：LocalAgentEngine.swift:376、435

### D02 公开网页搜索

对话入口：模型理解需求 → 调 search_web → 结果回传模型

直接入口：当前没有核实到独立原生网页搜索界面

来源：Bing 搜索页；不是 DeepSeek 官方联网搜索服务

网络：模型与 Bing 都通过系统可用网络访问

离线：搜索本身需要联网；对话还依赖模型可用

模型数据：关键词交给 Bing；链接、标题、摘要、取得时间可作为工具结果给 DeepSeek

依据：WebContentExecutor.swift:16；LocalAgentEngine.swift:540

### D03 网页正文读取与归纳

对话入口：模型可调用 fetch_web_content，再归纳取得的文字

直接入口：原生执行器可独立读网页，但目前对话是主要入口

来源：目标网站 + DeepSeek

网络：两者均可用 Wi-Fi / 移动数据

离线：新网页需要联网；已取得文字可本地保留，新的模型总结仍联网

模型数据：目标 URL 与网页请求发给网站；提取正文、标题、来源/时间给 DeepSeek

依据：WebContentExecutor.swift:46；LocalAgentEngine.swift:submitToolResults

### D04 商户人均 / 菜单 / 套餐价格

对话入口：模型选工具 → 本机检索/提取价格 → 模型解释

直接入口：已有 MerchantPriceExecutor；不代表新增独立按钮

来源：Bing + 候选网站；本机价格提取；DeepSeek 归纳

网络：检索网站和模型都使用联网通道

离线：无网无法取得新价格；查不到不能由模型填价

模型数据：店名、分店/城市与价格关键词到 Bing；价格证据、片段和来源给 DeepSeek

依据：MerchantPriceExecutor.swift:search

### D05 附近地点搜索

对话入口：通常先经模型，再调用真实 MapKit 搜索

直接入口：首页“附近”快捷卡当前也是 model.send，仍走模型

来源：CoreLocation 本机定位 + Apple MapKit 地点服务

网络：定位可部分依赖本机；地点搜索需要网络；模型也联网

离线：可能取得 GPS，但新商户检索与模型回复不能保证离线

模型数据：搜索中心/区域给地图服务；候选名称、地址、经纬度、距离等随工具结果给 DeepSeek

依据：WhaleHomeCanvas.swift:143、386；LocationExecutor.swift:119

### D06 “我在哪” / 位置转地址

对话入口：模型调用 get_current_location，再解释结果

直接入口：未核实独立位置查询按钮

来源：CoreLocation + Apple 反向地理编码

网络：GPS 不等于上网；地址解析与模型通常联网

离线：可能取得坐标；无法保证解析街道/城市；聊天第一步仍需模型

模型数据：当前工具结果包含用户坐标、精度、位置时间、地址字段，回传模型时会包含这些字段

依据：LocationExecutor.swift:9

### D07 天气预报

对话入口：模型调用 get_weather；真实预报来自 Open-Meteo

直接入口：首页天气快捷卡当前发送对话，不是免模型天气按钮

来源：Open-Meteo；地点解析依 Apple 地理编码

网络：天气 API 和模型都可走 Wi-Fi / 移动数据

离线：新预报需要联网；模型不能凭常识冒充实时天气

模型数据：查询坐标（请求保留4位小数）、日期到 Open-Meteo；结果含天气和坐标，可给 DeepSeek

依据：WeatherExecutor.swift:query、105；WhaleHomeCanvas.swift:163

### D08 打开地图 / 导航交接

对话入口：对话选择目的地通常经模型；交接在手机执行

直接入口：选已有地点的地图入口可直接交接，不必生成新对话

来源：iOS 地图 App；路线/地图数据由地图服务处理

网络：打开 App 是本机动作；新路线/在线地图一般联网

离线：已下载离线地图按系统能力决定；鲸鱼未承诺离线导航

模型数据：对话路径可发地点/目的地相关字段；外部地图自行处理路线，不把地图瓦片传给 DeepSeek

依据：LocationExecutor.swift:openNavigation

### D09 通过对话查 / 建 / 改日历

对话入口：通常经模型理解日期/事项；EventKit 本机读写；结果回传

直接入口：已有系统执行器；对话入口使用模型

来源：EventKit 本机日历；账户同步由 iOS/账户服务处理

网络：EventKit 操作可本地；模型用网；iCloud/Exchange同步可能用网

离线：本机缓存可读写，但完整自然语言闭环仍依赖模型

模型数据：相关事件标题、时间、地点、备注/记录ID等工具字段可能送 DeepSeek

依据：EventKitExecutor.swift；LocalAgentEngine.swift:encodeResult

### D10 首页“今日/近期日程”面板刷新

### D11 通过对话创建 / 修改提醒

对话入口：通常先经模型，确认后本机 EventKit 执行，再回传结果

模型数据：不会因眨眼/点按就自动向 DeepSeek 或丹青约上传数据

依据：WhaleHomeCanvas.swift；design/aurora-companion-v1/

### D32 切换“云后端”开发模式

对话入口：真实模式：手机 → 自有后端 → DeepSeek；不是免模型模式

直接入口：默认local表示手机直连远端模型；cloud按配置连接后端

来源：用户配置的服务器 + DeepSeek

网络：公网后端可用两种网络；内网地址通常需同网或已有可达连接

离线：后端不可达则该模式不可用；127.0.0.1在手机指手机自己

模型数据：对话文本、时间/时区、权限与工具结果先到自有服务器，随后按后端配置进入模型

依据：AppModel.swift:95、119；AgentClient.swift；backend/src/config.mjs

### D33 App运行时生图 / 视频 / 3D

对话入口：未来可用模型理解指令，但生成服务独立

直接入口：当前仅设计阶段用丹青约，不是 App 运行时已接入

来源：规划中的生成服务 / 存储

网络：真正生成需互联网与该服务；查看已下载资源可本地

离线：当前没有可离线运行的大型生成模型

模型数据：设计时素材已生成保存；App内每次点鲸鱼不会自动调用生图服务

依据：design/aurora-companion-v1/prompts.json；20_能力拓展方案.md

### D34 待办页直接新增 / 完成 / 恢复 / 删除

对话入口：若通过普通对话发起，参照D11；这个待办页路径不调用模型

直接入口：TodoView本机解析/界面操作，AppModel直接调用EventKit路由

来源：TodoQuickParser / EventKit 本机提醒；账户同步另算

网络：直接操作本身无需DeepSeek或互联网；系统提醒账户同步可能联网

离线：授权与本机提醒来源可用时，可以直接处理；规则解析的表达范围有限

模型数据：这次直接入口不把待办文本作为DeepSeek请求；之后聊天查询相关提醒时可能读取/回传

依据：TodoView.swift:submitText、TodoQuickParser；AppModel.swift:723、738、759、767

### D35 待办页“语音新增待办”

对话入口：此专用入口不发送到普通模型对话；普通语音聊天参照D25/D26

直接入口：VoiceInputController转写 → 本机待办规则解析 → 直接EventKit；不是通用离线大模型

来源：已配置时讯飞 / 否则Apple Speech；后续TodoQuickParser + EventKit

网络：识别音频仍按讯飞/系统识别条件用网；转写后的待办解析/保存无需DeepSeek

离线：是否能完成语音转写取决识别引擎及系统离线能力；不能承诺整个语音入口完全离线

模型数据：音频可能给讯飞或Apple识别服务；专用待办路径不把转写文字发给DeepSeek

依据：TodoView.swift:294、631、submitText；AppModel.swift:createTodoReminder
