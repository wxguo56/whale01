# 0.7.1 · 发现固定框架与极光层次恢复

交付日期：2026-11-14。用户明确选择：顶部频道标签和底部导航固定，只切换中间内容；配色与柔和阴影回到上一版的视觉方向。

0.7.0 将频道作为全屏页面打开，进入频道后底部主导航消失；背景与卡片趋于实色，使原有极光与柔和层次减弱。本次修正导航结构与视觉样式。

| 项目 | 最终行为 |
|---|---|
| 发现框架 | 固定“发现”标题、六个频道标签和系统底部三栏；取消全屏频道弹出 |
| 中间内容 | 在同一容器切换 AI 科技、A 股、游戏、音乐、新闻、热榜；只有内容短暂淡入 |
| 详情阅读 | 中间区域内部使用导航栈，保留详情返回按钮；外层频道和底部导航继续可用 |
| 分类标签 | AI/新闻分类、游戏分类、微博/知乎选择置于阅读滚动区外；缓存提示移到内容下方，刷新不挤动标签 |
| 状态保持 | 记住所选频道，各频道模型与缓存分别保留；首页听歌/新闻直接切到对应频道 |
| 极光配色 | 晨雾/深海背景与静态薄荷、蓝色光晕；选中标签恢复薄荷到天空蓝渐变 |
| 阴影层次 | 标签、卡片、常用操作和圆形按钮使用低透明度柔和投影；卡片使用玻璃材质、轻边框 |
| 可读性 | 保留 13pt 自定义字号下限、系统字体缩放、可读正文颜色、减少动态与减少透明度支持 |

选中标签文字与渐变端点对比度：浅色最低 5.55:1，深色最低 5.78:1（绿色端点 7.42:1）。大字号频道条可横向滚动，文章阅读区在分类标签下方。主页继续暂缓鲸鱼伙伴；草稿、语音检查、确认执行与音乐业务链路继续保留。
