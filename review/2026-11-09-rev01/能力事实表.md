## 4. 后端鉴权现场验证（2026-11-09）

后端已配置两个身份：手机 A、测试 B。现场请求 `http://10.219.86.103:8790`：

| 请求 | 结果 |
|---|---|
| `GET /healthz` | 200，`authRequired=true`，`modelMode=deepseek`，`executionMode=ios`，15 tools |
| 无 Token `GET /v1/capabilities` | 401 |
| A `GET /v1/capabilities` | 200，15 项能力 |
| A 创建 turn（`deferExecution=true`） | `completed`，conversation `conv_747226d3...` |
| B `GET /v1/turns/{A的turnId}` | 403 |
| B `GET /v1/conversations/{A的会话}` | 403 |
| A 读取同一 turn | 200 |

跨身份拒绝已由后端单测与现场请求双重确认；App 内访问码输入仍待真机验证。
