# 已知问题（0.3.0）

| 级别 | 问题 | 影响 | 处理 |
|---|---|---|---|
| P2 | 提醒去重只覆盖“同标题+同时间（±60 秒）的未完成提醒” | 改标题或改时间的重复请求仍会新建 | 0.3.0 起同标题同时间返回 `deduplicated`；更复杂的语义合并未做 |
| P2 | 原生执行 20 秒超时后返回 `execution_unknown` | 写操作可能已生效，需用户到系统 App 核对 | 已阻止盲目重试；无自动核对能力 |
| P2 | 日程冲突只在结果里报告数量，不阻止写入 | 用户可能确认后仍产生重叠 | 需要产品决定是否改为“冲突即拒绝” |
| P2 | 讯飞语音需要三件套配置 | 当前只能使用系统听写 | 配置 `XFYUN_APP_ID/API_KEY/API_SECRET` 后复验 |
| P2 | 讯飞 TTS 播报与打断未实现 | 鲸鱼只输出文字，不朗读 | 未在本版本范围；不冒充已支持 |
| P2 | App Intent 仅“创建提醒”一个入口 | 快捷指令能力有限 | 已编译，待真机加进快捷指令验证 |
| P2 | 分享扩展与 App Intent 尚未真机验证 | 不能宣布已交付 | 0.3.0 安装后按验收记录逐条执行 |
| P3 | 分享扩展在免费签名下无 App Group | 依赖 URL 交接，正文超过 1500 字时不随 URL 传递 | App Group 通道在正式签名可用；免费签名以短文本为主 |

## 环境限制

- 免费签名不包含 HealthKit / WeatherKit / App Groups。
- iOS 26 锁屏会丢弃注入式 HID 触控；自动化验收需保持解锁。
- 系统权限弹窗忽略注入触控，需人工点击。
